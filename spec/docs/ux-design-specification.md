## Executive Summary

Lilanaya (Prana) is a platform to explore strategies across configurable worlds using deterministic (seeded) simulations, clear rankings, and explainability. The platform enables World Creators to define game worlds, Strategy Creators to author and test strategies, and Spectators to discover and analyze results.

**Magic Moment:** Creating a strategy, letting it run in a world, and seeing how it performs — the moment of discovery when your strategy's results come to life.

## 2. Core User Experience

### 2.1 Defining Experience

**Primary User Action:** Create strategies

**Core Experience Goal:** Make it absolutely effortless to create a strategy in a world and then let it run.

**Most Critical Interaction:** Strategy creation — this is the heart of the platform and must be intuitive, fast, and rewarding.

**Platform:** Web application (vanilla JavaScript front end, Rust back end), optimized for desktop with responsive mobile support.

### 2.2 Desired Emotional Response

**Core Emotions:** Analytical, Empowered, Creative

**User Experience Goal:** Users should feel like researchers and strategists discovering insights. The platform enables them to:

- **Analytical:** Think through problems systematically, analyze patterns, and deduce principles
- **Empowered:** Discover which strategies work best and extract actionable insights
- **Creative:** Explore "what if" scenarios and test different behavioral approaches
- **Curiosity-Driven:** Driven to see how specific behaviors perform in worlds with specific rules

**The Magic:** Like Axelrod's tournament revealed principles ("be nice, be forgiving, don't be a pushover, be clear"), Lilanaya lets users apply mathematics and simulation to arrive at conclusions about how to act. The platform transforms curiosity into discovery, enabling users to extract wisdom from data.

**Design Implication:** The UX must support analytical thinking, make insights discoverable, and celebrate the "aha moments" when patterns emerge. Results should be presented in ways that facilitate learning and insight extraction, not just data display.
